# AI SEO Implementation Checklist

A practical implementation checklist for technical SEO, AI search readiness, content quality, structured data, entities, internal linking, authority, and measurement.

> **Purpose:** Use this checklist to identify implementation gaps and document completed work. Checking an item does not guarantee rankings, indexing, traffic, or visibility in AI-generated answers.

---

## 1. Website Access & Crawlability

### Basic accessibility

- [ ] Confirm the website resolves correctly over HTTPS.
- [ ] Confirm HTTP redirects to HTTPS where appropriate.
- [ ] Confirm the preferred hostname is consistent.
- [ ] Check both www and non-www versions.
- [ ] Confirm important pages return successful HTTP responses.
- [ ] Identify unintended 3xx redirects.
- [ ] Identify 4xx errors affecting important URLs.
- [ ] Identify 5xx server errors.
- [ ] Check whether important resources are accessible to crawlers.
- [ ] Confirm the site does not depend entirely on inaccessible client-side interactions for essential content.

### Crawl controls

- [ ] Review robots.txt.
- [ ] Confirm robots.txt is accessible.
- [ ] Check that important sections are not unintentionally disallowed.
- [ ] Check for conflicting crawl directives.
- [ ] Review noindex directives.
- [ ] Review X-Robots-Tag headers where applicable.
- [ ] Confirm important pages are not accidentally blocked.
- [ ] Review parameterized URLs.
- [ ] Review faceted navigation.
- [ ] Identify crawl traps.
- [ ] Review unnecessary URL variations.
- [ ] Check internal links to blocked URLs.

---

# 2. Indexing & Canonicalization

- [ ] Identify the canonical URL for every important page type.
- [ ] Check canonical tags.
- [ ] Confirm canonical URLs are absolute and valid.
- [ ] Check for canonical chains.
- [ ] Check for conflicting canonical signals.
- [ ] Identify duplicate pages.
- [ ] Review near-duplicate pages.
- [ ] Check HTTP/HTTPS duplication.
- [ ] Check www/non-www duplication.
- [ ] Check trailing-slash inconsistencies.
- [ ] Review URL parameters.
- [ ] Review pagination where applicable.
- [ ] Check important pages for accidental noindex directives.
- [ ] Compare sitemap URLs with canonical URLs.
- [ ] Compare sitemap URLs with indexable URLs.
- [ ] Identify important pages that are discovered but not indexed.
- [ ] Investigate important pages that are crawled but not indexed.
- [ ] Review redirects after URL changes.

---

# 3. XML Sitemap

- [ ] Confirm an XML sitemap exists.
- [ ] Confirm the sitemap is accessible.
- [ ] Confirm the sitemap contains canonical URLs.
- [ ] Remove redirected URLs where appropriate.
- [ ] Remove non-indexable URLs.
- [ ] Remove broken URLs.
- [ ] Review sitemap freshness.
- [ ] Confirm important content types are represented.
- [ ] Check sitemap references in robots.txt.
- [ ] Submit the sitemap through relevant webmaster tools.
- [ ] Monitor sitemap processing errors.
- [ ] Review changes after major site migrations.

---

# 4. Site Architecture

- [ ] Identify the primary sections of the website.
- [ ] Identify important cornerstone pages.
- [ ] Identify supporting content.
- [ ] Organize related content into logical topical groups.
- [ ] Keep important pages reasonably accessible through internal navigation.
- [ ] Identify orphan pages.
- [ ] Review excessive click depth.
- [ ] Review navigation labels.
- [ ] Check category structures.
- [ ] Review breadcrumb navigation.
- [ ] Check internal links after URL changes.
- [ ] Remove unnecessary navigation duplication.
- [ ] Make important pages easy for users to discover.

---

# 5. Search Intent & Content Planning

- [ ] Define the primary purpose of each important page.
- [ ] Identify the dominant search intent.
- [ ] Identify the target audience.
- [ ] Identify the problem the page solves.
- [ ] Review competing search results.
- [ ] Identify important subtopics.
- [ ] Identify questions users are likely to ask.
- [ ] Map supporting pages to broader topics.
- [ ] Avoid creating multiple pages targeting the same intent without a clear reason.
- [ ] Identify content gaps.
- [ ] Identify outdated content.
- [ ] Identify thin or low-value pages.
- [ ] Create an update plan for priority content.
- [ ] Define measurable objectives for important content.

---

# 6. Content Quality

- [ ] Ensure the page provides a clear answer to its primary purpose.
- [ ] Write a useful introduction.
- [ ] Use descriptive headings.
- [ ] Organize information logically.
- [ ] Put important information where users can easily find it.
- [ ] Remove unnecessary repetition.
- [ ] Check factual accuracy.
- [ ] Update outdated claims.
- [ ] Explain technical concepts clearly.
- [ ] Use examples where they improve understanding.
- [ ] Add original observations where appropriate.
- [ ] Distinguish facts from opinions.
- [ ] Attribute important claims to appropriate sources.
- [ ] Avoid unsupported guarantees.
- [ ] Review content from the user's perspective.
- [ ] Check whether the page provides enough context to be useful independently.
- [ ] Improve unclear sections.
- [ ] Remove content created solely to manipulate search visibility.

---

# 7. AI Search Readiness

- [ ] Clearly identify what the website is about.
- [ ] Clearly identify the organization, person, or entity behind the website.
- [ ] Use consistent names and descriptions.
- [ ] Make important facts explicitly understandable.
- [ ] Organize related information into coherent topical sections.
- [ ] Answer important questions directly.
- [ ] Use descriptive headings and subheadings.
- [ ] Avoid hiding essential information behind unnecessary interactions.
- [ ] Make important content available in crawlable HTML where appropriate.
- [ ] Support important claims with evidence where appropriate.
- [ ] Maintain consistency between pages describing the same entity.
- [ ] Review whether important entities and their relationships are clear.
- [ ] Review author information where relevant.
- [ ] Review organization information where relevant.
- [ ] Avoid publishing disconnected articles solely to target individual keywords.
- [ ] Build topical depth around meaningful user needs.
- [ ] Keep factual information current.
- [ ] Monitor how important information is represented across search experiences.

---

# 8. Structured Data

- [ ] Identify applicable Schema.org types.
- [ ] Select the most accurate schema type.
- [ ] Confirm structured data describes the page accurately.
- [ ] Ensure structured data reflects visible information where required.
- [ ] Avoid adding unsupported claims through markup.
- [ ] Review required properties.
- [ ] Review recommended properties.
- [ ] Validate JSON-LD syntax.
- [ ] Check for invalid property values.
- [ ] Check for conflicting structured-data entities.
- [ ] Review Organization markup where appropriate.
- [ ] Review Person markup where appropriate.
- [ ] Review Article markup where appropriate.
- [ ] Review Product markup where appropriate.
- [ ] Review Breadcrumb markup where appropriate.
- [ ] Test structured data after major template changes.
- [ ] Monitor relevant search enhancements.
- [ ] Remove obsolete markup when page types change.

---

# 9. Entity Optimization

- [ ] Identify the primary entity of each important page.
- [ ] Use consistent entity names.
- [ ] Clearly identify organizations.
- [ ] Clearly identify people.
- [ ] Clearly identify products or services where applicable.
- [ ] Define relationships between relevant entities.
- [ ] Maintain consistent business information.
- [ ] Review organization descriptions.
- [ ] Review author identity information.
- [ ] Review entity references across important pages.
- [ ] Use authoritative references where appropriate.
- [ ] Avoid contradictory entity information.
- [ ] Review structured data relationships.
- [ ] Check whether important entities are described consistently across the website.

---

# 10. Internal Linking

- [ ] Identify cornerstone pages.
- [ ] Link supporting content to relevant cornerstone pages.
- [ ] Link cornerstone pages to useful supporting resources.
- [ ] Use descriptive anchor text.
- [ ] Avoid excessive exact-match anchor repetition.
- [ ] Check links for relevance.
- [ ] Remove broken internal links.
- [ ] Identify orphan pages.
- [ ] Review internal links after URL changes.
- [ ] Avoid linking unrelated pages simply to increase link counts.
- [ ] Link to deeper resources when they genuinely help users.
- [ ] Review important pages with very few internal links.

---

# 11. Images & Media

- [ ] Use descriptive filenames where practical.
- [ ] Write useful alt text for meaningful images.
- [ ] Avoid keyword stuffing in alt text.
- [ ] Compress unnecessarily large images.
- [ ] Use appropriate image dimensions.
- [ ] Review responsive image behavior.
- [ ] Check lazy-loading implementation.
- [ ] Ensure important visual information has an appropriate textual equivalent where necessary.
- [ ] Remove unnecessary duplicate images.
- [ ] Review image accessibility.

---

# 12. Performance & Technical Experience

- [ ] Review Core Web Vitals.
- [ ] Review page loading performance.
- [ ] Identify large resources.
- [ ] Review JavaScript execution.
- [ ] Review CSS delivery.
- [ ] Review image loading.
- [ ] Check mobile performance.
- [ ] Check desktop performance.
- [ ] Review third-party scripts.
- [ ] Remove unnecessary resources where appropriate.
- [ ] Check caching configuration.
- [ ] Review server response times.
- [ ] Test important templates after performance changes.

---

# 13. Off-Page Authority

- [ ] Create resources worth referencing.
- [ ] Publish original research where possible.
- [ ] Publish practical tools and templates.
- [ ] Participate meaningfully in relevant communities.
- [ ] Contribute useful information to relevant projects.
- [ ] Seek relevant editorial mentions.
- [ ] Build relationships within the industry.
- [ ] Monitor brand mentions.
- [ ] Review referring domains.
- [ ] Investigate suspicious backlink patterns.
- [ ] Avoid automated backlink generation.
- [ ] Avoid mass irrelevant directory submissions.
- [ ] Avoid manipulative link schemes.
- [ ] Avoid placing links where they provide no user value.
- [ ] Prioritize relevance and usefulness over raw backlink volume.

---

# 14. Measurement

- [ ] Configure Google Search Console.
- [ ] Configure appropriate analytics.
- [ ] Monitor indexed pages.
- [ ] Monitor organic impressions.
- [ ] Monitor organic clicks.
- [ ] Monitor important queries.
- [ ] Monitor important landing pages.
- [ ] Monitor referral traffic.
- [ ] Monitor conversions.
- [ ] Monitor crawl and indexing issues.
- [ ] Document major technical changes.
- [ ] Document major content changes.
- [ ] Compare performance over meaningful periods.
- [ ] Avoid judging SEO changes from isolated daily fluctuations.
- [ ] Review whether traffic is producing useful business outcomes.

---

# 15. Maintenance

- [ ] Schedule periodic technical audits.
- [ ] Review important pages after major website changes.
- [ ] Review redirects after URL changes.
- [ ] Review sitemap health.
- [ ] Review robots.txt after major changes.
- [ ] Review structured data after template changes.
- [ ] Review broken links.
- [ ] Review outdated content.
- [ ] Review important entity information.
- [ ] Review analytics and Search Console configuration.
- [ ] Document significant changes.
- [ ] Maintain a record of completed improvements.

---

# Implementation Priority

A practical sequence is:

1. Access & crawlability
2. Indexing & canonicalization
3. Sitemap
4. Site architecture
5. Search intent
6. Content quality
7. AI search readiness
8. Structured data
9. Entity optimization
10. Internal linking
11. Performance
12. Authority
13. Measurement
14. Maintenance

Do not assume that completing more checklist items automatically produces better rankings. Prioritize issues according to their actual impact on accessibility, usefulness, accuracy, and the goals of the website.

---

# Evidence & Documentation

For important implementation decisions, record:

- Date
- URL
- Issue identified
- Evidence
- Recommended action
- Action taken
- Validation method
- Result
- Follow-up date

Keeping an implementation record makes SEO work easier to audit, reproduce, and improve.

# Disclaimer

This checklist is an educational resource.

Search engines and AI-powered search systems change over time. Completing checklist items does not guarantee rankings, indexing, traffic, citations, inclusion in AI-generated answers, or conversions.

Validate recommendations against current official documentation and the specific technical environment of the website being audited.
